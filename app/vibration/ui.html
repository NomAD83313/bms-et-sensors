Bus

Poll interval 0 polls as fast as the bus allows. Profiles: basic = velocity, displacement, frequency, acceleration, temperature; extended adds statistics and fault codes; full adds spectrum energy.

Adapter baud only changes how this Pi opens the port; nothing is written to the sensors. Use it when the sensors already run at that rate. All sensors on one bus must share one rate.

Reprogram sensor baud

Writes the rate into every registered sensor (unlock, write, save), then switches the adapter to it. A sensor that misses the change stays at the old rate; find it with Scan at that rate.
