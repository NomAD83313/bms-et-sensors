Applying a different area or Full frame pauses detection and event recording, deletes the previous baseline and normal sessions, and requires new learning. Pi camera capture

VIDEO OR SNAPSHOTS

Checking capture settings…

The full sensor view is preserved at every resolution. Wide outputs add black side bars without cropping or stretching. Full-sensor video is limited to 15 FPS. Video: choose resolution and FPS; exposure is automatic. The live preview is limited to 10 FPS. Snapshots: choose resolution, interval and exposure; event video uses the selected resolution and snapshot rate. Applying settings restarts capture and pauses detection and event recording. Check the image and learn the normal view again after changing capture settings.

Normal sessions

Checking saved normal sessions…

Save up to 8 normal states, with any names or reasons. Add keeps existing sessions; Learn new baseline starts over after successful learning. Replace records a new session for the selected learning time. Delete rebuilds the remaining sessions and pauses detection. Keep anomalies out of every session.

Learning captures one normal frame every two seconds. Longer runs cover more normal variation and save more JPEGs. Each session contains 30–120 frames. Name and comment are optional. New baseline replaces the saved sessions after successful learning; Add normal session keeps them.

Changing the model stops detection and event recording, deletes the previous baseline and normal sessions, and requires new learning. MobileNetV3 and MobileNetV4 produce the same stride-sixteen heatmap. Experimental candidates: verify detection sensitivity in your scene after learning. Scores and thresholds are specific to each model.

One frame detects shorter changes faster, with more false alerts. Two or more require consecutive analyzed frames. Applies immediately; no new learning is needed.

Analysis uses the selected area from the full source image; the browser keeps a separate 960 × 540 preview. Maximum input presets are 16:9 bounds. An area fits inside those bounds with its own proportions and is never enlarged; the actual input dimensions appear below. Full frame keeps the selected preset dimensions. Changing input size stops detection, deletes the previous baseline and normal sessions, and requires new learning. Larger inputs use more CPU and memory; upscaling beyond the analysis image adds no detail. Event recording pauses until learning completes; continuous recording stays available.
